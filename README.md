# 🧭 যাযাবর মিটার (Jajabor Meter)

> **লাইভ ডোমেন:** [http://jajabor.mdrasel.site/](http://jajabor.mdrasel.site/)  
> **ট্যাগলাইন:** *আপনি কি আসল যাযাবর নাকি খাটের রাজা?*

বাংলাদেশের ৬৪ জেলার কালারফুল ও ইন্টারেক্টিভ এসভিজি ম্যাপ ভিত্তিক একটি ফানি ও ভাইরাল ট্রাভেলার ওয়েব অ্যাপ্লিকেশন। এখানে ব্যবহারকারী কোনো জোরপূর্বক লগইন ছাড়াই সম্পূর্ণ ফ্রিতে ঘুরে আসা জেলাগুলো সিলেক্ট করে নিজের স্কোর মাপতে পারে, ফাঁপর ডিটেক্টরে মজার কুইজের উত্তর দেয় এবং সোশ্যাল মিডিয়ায় রোস্টিং সনদপত্র শেয়ার করে বন্ধুদের চ্যালেঞ্জ জানাতে পারে!

---

## ✨ মূল আকর্ষণীয় ফিচারসমূহ

1. **ইন্টারেক্টিভ ৬৪ জেলার ভেক্টর ম্যাপ:**
   * প্রতিটি জেলার জন্য নিখুঁত ও মসৃণ ক্লিকেবল এসভিজি পাথ।
   * বিভাগীয় ফিল্টার বার (ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা, সিলেট, বরিশাল, রংপুর, ময়মনসিংহ)।
   * জেলাভিত্তিক বিখ্যাত খাবার এবং ফানি ফ্যাক্ট টুলটিপ।
2. **ফাঁপর ডিটেক্টর (Lie-Detector Quiz):**
   * নির্দিষ্ট কিছু জেলায় (সিলেট, বগুড়া, কক্সবাজার, কুমিল্লা ইত্যাদি) ক্লিক করলে ফানি প্রশ্ন আসে। সঠিক উত্তর দিলে তবেই জেলা তালিকায় যোগ হয়!
3. **স্পিড অ্যালার্ট (Anti-Spam Meme Popup):**
   * কেউ দ্রুত ৩ সেকেন্ডে ৫+ জেলা ক্লিক করলেই মজার ওয়ার্নিং আসে: *"ভাই, আপনি কি নাসার রকেটে করে ভ্রমণ করতেছেন? একটু দম নেন!"*
4. **ট্যুরের কাণ্ডকারখানা চেকলিস্ট:**
   * ভ্রমণে সবার সাথে ঘটা বাস্তব ফানি স্মৃতিগুলো (যেমন: সাজেক যাওয়ার প্ল্যান বাতিল, হোটেলে ঢুকে আগে ওয়াইফাই খোঁজা) টিক দেওয়ার অপশন।
5. **স্পেশাল কম্বো ট্রফি:**
   * নির্দিষ্ট জেলাগুলো সম্পূর্ণ করলে বিশেষ ব্যাজ আনলক হয় (উদাঃ ইলিশ বিশারদ, চা-বাগান বিশেষজ্ঞ, পাহাড়ি মার্বেল)।
6. **রোস্টিং সনদপত্র ও ১-ক্লিক সোশ্যাল শেয়ার:**
   * **১-ক্লিক হাই-রেজ্যুলেশন (HD) ডাউনলোড:** `html-to-image` ও Retina Sharpness দিয়ে ঝকঝকে PNG ডাউনলোড।
   * **১-ক্লিক সোশ্যাল শেয়ার:** মোবাইল নেটিভ শেয়ার শিট, WhatsApp ও Facebook ডিরেক্ট ডায়ালগ এবং রেডিমেড বাংলা ভাইরাল ক্যাপশন কপি।
7. **১v১ বন্ধু ভ্রমণ যুদ্ধ (`/compare`):**
   * লিংক শেয়ার করে দুই বন্ধুর ভ্রমণ স্কোর, পদবী, এবং কে কোন কোন জেলায় এগিয়ে তা পাশাপাশি দেখা যায়।
8. **গেস্ট মোড ও অপশনাল গুগল লগইন (১০০% ফ্রি):**
   * কোনো ইউজারকে লগইন করতে বাধ্য করা হয় না।
   * গেস্টরা সরাসরি নাম লেখার পাশাপাশি **ডিভাইস থেকে নিজের ছবিও আপলোড** করতে পারে (যা ব্রাউজারেই অপটিমাইজ হয়, কোনো ক্লাউড স্টোরেজ খরচ নেই)।
   * যারা ১-ক্লিকে নাম ও ছবি চায় তাদের জন্য অপশনাল গুগল সাইন-ইন।
9. **১০০% নিখুঁত SVG আইকন:**
   * UI ইন্টারফেসে কোনো ইমোজি ব্যবহার না করে সর্বত্র `lucide-react` ভেক্টর আইকন ব্যবহৃত হয়েছে।
10. **ফানি ৪০৪ ও এরর পেজ:**
    * ৪০৪: *"রাস্তা ভুলে ভারতে ঢুকে গেছেন নাকি?"*
    * Error: *"গাড়ির টায়ার পাংচার হয়েছে!"*

## 🛠️ ব্যবহৃত টেকনোলজি

* **Framework:** Next.js 14 (App Router) + TypeScript
* **Styling:** Tailwind CSS + clsx + tailwind-merge
* **Vector Icons:** Lucide React (১০০% SVG)
* **Animation & Motion:** Framer Motion + Canvas Confetti
* **Export & Capture:** html-to-image
* **Data & Bounds:** Bangladesh UN OCHA / BBS 64 District Coordinates

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম

প্রজেক্ট ডিরেক্টরিতে যান:
```bash
cd E:\Code\Personal\jajabor-meter
```

প্রয়োজনীয় প্যাকেজ ইনস্টল করুন (যদি না করা থাকে):
```bash
npm install
```

ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

## 📦 প্রোডাকশন বিল্ড ও ডেপ্লয়মেন্ট গাইড (`http://jajabor.mdrasel.site/`)

### ১. প্রোডাকশন বিল্ড তৈরি:
```bash
npm run build
```

### ২. সার্ভার রান করা (Node.js / VPS / cPanel):
```bash
npm run start
```
ডিফল্টভাবে এটি পোর্ট `3000`-এ চালু হবে।

### ৩. Nginx Reverse Proxy কনফিগারেশন (`jajabor.mdrasel.site` এর জন্য):
```nginx
server {
    listen 80;
    server_name jajabor.mdrasel.site;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### ৪. PM2 দিয়ে ব্যাকগ্রাউন্ডে চালু রাখা:
```bash
pm2 start npm --name "jajabor-meter" -- start
pm2 save
```
